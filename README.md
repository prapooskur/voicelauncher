![VoiceLauncher image](app/src/main/res/mipmap-xxxhdpi/ic_launcher.webp)

Vivo doesn't have a way to launch the default android assistant in OriginOS, so I created this. 

When opened, this app calls `Intent.ACTION_VOICE_COMMAND`, then immediately exits. Place it in the launcher or smart sidebar for a convenient way to launch the assisant.
